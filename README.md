# ポートフォリオ テンプレート（1 ファイル + images）

技育プロジェクト ミニカンファレンス 2026.08
作品を並べて見せる、個人のポートフォリオサイトのテンプレートです。

## ファイル構成

```
index.html    ← これ 1 枚（CSS も JavaScript も中に入っています）
profile.jpg   ← プロフィール写真（900 × 900・正方形）
work1.jpg     ← 作品 1（1000 × 750）
work2.jpg     ← 作品 2（1000 × 750）
work3.jpg     ← 作品 3（1000 × 750）
ogp.jpg       ← SNS シェア用サムネイル（1200 × 630）
```

**フォルダは作らず、全部同じ場所に並べています。**
GitHub にアップロードするときに「全部まとめて選んでドラッグ＆ドロップ」できるようにするためです。
同梱の画像はすべてサンプルです（そのまま使っても、差し替えても OK）。

## セクション構成

HEADER（固定メニュー）／ HERO（写真・名前・ひとこと）／ ABOUT（自己紹介＋プロフィール項目）
／ WORKS（作品カード 3 枚）／ SKILLS（できること）／ TIMELINE（これまでのこと）／ CONTACT ／ FOOTER

## 中身の構成

| ブロック | 役割 | 目印 |
| --- | --- | --- |
| head エリア | タイトル・SNS シェア設定（OGP） | `<title>` / `<meta>` |
| style エリア | 見た目（CSS） | `<style> … </style>` |
| body エリア | 中身（HTML） | `<body> … </body>` |
| script エリア | 動き（JavaScript） | `<script> … </script>` |

## 画像の差し替え方（いちばん簡単な方法）

**index.html と同じ場所にある画像を、同じ名前の自分の画像で上書きするだけ。**
HTML は一切さわらなくて構いません。

- ファイル名は必ず同じに（`profile.jpg` を差し替えるなら、新しい画像も `profile.jpg`）
- 拡張子が違うとき（`.png` を使いたいなど）は、HTML 側の `src="profile.jpg"` も同じ名前に直す
- 大文字小文字は区別されます（`Profile.jpg` ≠ `profile.jpg`）
- 1 枚あたり **300KB 以下**を目安に（大きすぎると表示が遅くなります）

作品を増やしたいときは、画像を同じ場所に置いて、カードごとコピーします。

```html
<a class="work-card" href="作品のURL">
  <img src="work4.jpg" alt="作品 4" />
  <div class="work-body">
    <span class="work-tag">個人開発</span>
    <h3>作品のタイトル</h3>
    <p>ひとこと説明。</p>
  </div>
</a>
```

`alt="…"` は画像が表示されないときや読み上げソフトのための説明文です。必ず書きましょう。

## まずはここから（テーマ設定）

style エリアの先頭にある `:root` を変えると、サイト全体の雰囲気が変わります。

```css
:root {
  --main-color: #0e9594;  /* 見出し・ボタンの色 */
  --dark-color: #1f2b33;  /* 見出し文字・フッター */
  --soft-color: #f1f7f7;  /* 薄い背景 */
}
```

| テーマ | main-color | dark-color | soft-color |
| --- | --- | --- | --- |
| ミント（初期値） | `#0e9594` | `#1f2b33` | `#f1f7f7` |
| パープル | `#6c5ce7` | `#241f3a` | `#f4f2fd` |
| オレンジ | `#e8590c` | `#3a2418` | `#fdf5f0` |
| モノトーン | `#333333` | `#111111` | `#f5f5f5` |

トップの背景を写真にしたいときは、style エリアの `.hero` の `background` を
`url("hero.jpg") center/cover;` に書き換え、`hero.jpg` を同じ場所に置きます。

## セクションを増やす・減らす

- **作品を増やす** … `<a class="work-card"> … </a>` をまるごとコピーして貼る
- **スキルを増やす** … `<li>HTML</li>` をコピーして貼る
- **年表を増やす** … `<li><span class="year">…</span>…</li>` をコピーして貼る
- **セクションごと消す** … `<section id="skills"> … </section>` を丸ごと削除し、ヘッダーのメニューからも該当行を消す

## 公開する（セッション③）

1. GitHub にリポジトリを作る
2. `index.html` と画像 5 枚を**すべて選んでまとめてドラッグ＆ドロップ**（フォルダがないので迷いません）
3. Settings → Pages → Branch: `main` / `(root)` → Save
4. `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開完了

公開後、head エリアの `og:image` を
`https://<ユーザー名>.github.io/<リポジトリ名>/ogp.jpg`
のような**完全なアドレス**に書き換えると、SNS でシェアしたときにサムネイル付きカードが出ます。

## 公開前チェック

- 顔写真を載せるかは自由。アバターやイラストでも構いません
- 住所・学籍番号・電話番号など、載せる必要のない個人情報を書いていないか
- 作品の画像は自分で撮影・作成したもの、または利用が許可されているものか
- チーム制作の作品は、公開してよいか仲間に確認したか
- 一度公開したものは消えないつもりで — 全世界に見せて大丈夫か
